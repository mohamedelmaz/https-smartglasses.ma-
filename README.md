# 🚀 smartglasses.ma – مشروع موقع النظارات الذكية

**الموقع الرسمي:** [www.smartglasses.ma](https://www.smartglasses.ma)

---

## 📖 عن المشروع

موقع متكامل لبيع النظارات الذكية في المغرب، تم بناؤه كتطبيق صفحة واحدة (SPA) مع دعم كامل للغتين **العربية** و **الفرنسية**.  
يحتوي على جميع الصفحات الأساسية: الرئيسية، المنتجات، المميزات، سياسات (الإرجاع، الخصوصية، الشروط، الضمان)، دليل المستخدم، صفحة 404، ونموذج طلب متكامل.

---

## 🛠️ التقنيات المستخدمة

- **HTML5** – هيكل الصفحات
- **Tailwind CSS** – التصميم والتجاوب
- **JavaScript (vanilla)** – المنطق، الترجمة، النماذج، التنقل
- **Iconify** – أيقونات متجهة
- **Google Fonts** – خطوط Cairo و Tajawal
- **JSON-LD** – بيانات منظمة لـ SEO
